## 当前基线

| 项目 | 状态 |
|---|---|
| 六格 | 关注对象：项目及分析成果／产品使用与运行；期望结果：查明现状／形成判断／改变状态 |
| 产品场景 P01–P15 | 来自已确认需求；P01 的发现/选用和 P12 的跟踪/控制按业务子任务跨格 |
| 支撑能力 C01–C31 | 原 31 项归为能力和操作覆盖，不再称作 31 个产品场景 |
| 业务对象 O01–O30 | 作为规则与契约的建模依据，不要求独立 CRUD 或 30 个聚合 |
| DDD 边界 B1–B7 | 按语言、规则权威和一致性识别；六格不等于六个上下文，七个业务边界不等于七个进程 |
| 实现核查 | 已有分层与部分业务模块隔离；已统一应用输入契约、公开编码与用例路由；原子发布及查询读取端口保持 |
| 验证 | 架构门禁本轮通过；文档检查不替代产品测试、Native/分发或性能认证 |
