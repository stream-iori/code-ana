## P1-01：装配和基本运维

- [ ] 将 P0 验证实现归入窄接口；CLI 只发类型化任务，daemon 为装配入口，query 不直接依赖 SQLite 实现。
- [ ] 产品化 endpoint 注册/过期处理、单实例锁、握手、不兼容升级提示、drain、用户配置 generation。
- [ ] 任务登记、排队/执行、事件游标和终态保留；明确过期后返回 unavailable，不宣称无限 exactly-once。
- [ ] 同目标串行、项目间公平排队、全局内存预约、受限工作池、worker 崩溃清理和空闲回收。
- [ ] 启动时核对 catalog 提交记录和中断 attempt；已提交回报原结果，未提交标 interrupted，来源不明目录不自动删除。
- [ ] 建独立 annotation 存储边界与 annotation revision 接口，查询预留固定该版本的位置；用户编辑/绑定产品操作在 P2。
- [ ] 能力注册表仅暴露已实现操作/语言/版本；尚未实现功能明确 unsupported。

验收：两个项目的相同相对路径/模块名不串数据；linked worktree 的活动目标隔离。服务重启后能够解释已提交和中断任务。

## P1-02：配置、发现和捕获

- [ ] 完成 Java 配置全路径、FieldOrigin、EffectiveConfig 与 CLI presence；module 覆盖、源码集与 scope 映射有对照夹具。
- [ ] 固定物理 Maven 模块与发布标签映射；MAIN 不读 TEST，GENERATED 按上下文归属；排除工具缓存/内部 checkout/review worktree，不扁平化不支持的混合版本/JPMS 图。
- [ ] plain 显式根可运行；Maven 支持 fixture 所覆盖的父子模块、已有有效模型/classpath metadata；列出不支持的 profile/属性/模型条件。
- [ ] 对必须执行 Maven 才能确定的上下文返回缺口和 BuildAdvice，产品 discovery 不调用会执行插件/代码的构建命令。
- [ ] Java 25 原生适配器、目标 JDK 编译器桥与目标 Java 版本分开；产品仅声明 P0-04a 实际验收过的版本，未知/错配 JDK 与 vm_classpath=false 明确拒绝；缺 source_version 且无法发现时明确拒绝，不猜默认版本。
- [ ] 捕获源码/XML/控制文件/JAR/生成源码/所需 JDK 产物；清单改变重试有上限，补充输入必须封存后才能分析。
- [ ] 校验已有产物与源码/工具链/选项的对应；无法证明的 metadata 不静默当成可信 classpath。外部准备后必须新任务重新捕获。
- [ ] 接受 Gradle 配置时明确“当前能力不支持”，不得改用 plain 或偷偷扫描；混合项目启用未安装语言也不得静默忽略。

验收：MAIN/TEST、不同 Java 版本、多模块 JAR 的 world/profile 正确；配置注释或报告开关变化不会单独使语义失效；T19～T24 的 Java 场景通过。

## P1-03：全量事实

```text
捕获的完整语义输入 -> javac parse/analyze -> 独立 Java 模型 / ASM
         -> 声明 / 类型 / 成功绑定与失败查找依赖
         -> 调用点 / 引用 / 来源 / coverage
         -> Java 内部求解结束 -> 冻结 -> 分块交付
```

- [ ] 从 P0 的代表用例扩大到完整 java-basic/java-modules：重载、构造器、继承、接口、字段读写、注解、外部符号和未解析出现。
- [ ] 稳定模块/world/声明身份；位置按捕获字节，保留重复调用，不使用数据库 rowid 作公共身份。
- [ ] 输出独立模型中的泛型/实例化类型、SAM/方法引用、二进制名、源码注解和绑定证据；原始 javac 诊断不能被报告级别吞掉。
- [ ] 输出语言查询所需 facets；声明契约、成功依赖、失败查找桶和来源同时保存。
- [ ] 解析失败的 owner 没有“保留旧事实充当最新”的路径；生成声明有来源链，零事实文件也有 coverage。
- [ ] Java 内部完成绑定与求解后冻结；桥接层按块输出，host/daemon 均不积累无限序列化副本。

验收：P1 声明支持的源码构造都有 fixture 对照；不支持语法、缺 classpath、缺 JDK 分别给出能力缺口，不能返回完整空结果。

## P1-04：校验、门禁、发布和单步查询

- [ ] CandidateValidator 检查传输完整性、输入/profile/baseline、owner/引用、coverage/provenance；失败在提交前停止。
- [ ] HealthEvaluator 独立输出 assessment/gate；冻结 P1 支持的质量策略与 blocking codes，不把放宽门禁写成质量提高。
- [ ] full/delta 均走同一 Publisher；catalog 返回本次实际提交身份，报告不得回头读 active head 代替它。
- [ ] 实现 resolve、search-code、structure、calls、call-sites、references、source；selector 覆盖模块/world/scope/重载/外部实体，unique 歧义失败。
- [ ] 查询读固定 ReadContext；calls 投影去重而 call-sites 保留全部出现，possible 目标不混入默认 resolved 关系。
- [ ] source 读取当前文件并核对 hash；不匹配报错，提示重新索引或显式选冻结版本；历史读取接口只读 blob。
- [ ] 所有输出按公共身份与位置稳定排序，基本分页/字节预算/证据随首个命令一起实现。

验收：两个同目标调用返回 1 条 calls、2 条 call-sites；缺失目标仍能读调用现场；活动 head 更新不影响进行中的查询。

## P1-05：pipeline、分页和输出

- [ ] pipeline JSON 经类型/能力预检后一次提交；整个执行固定同一 revision/profile/world/scope，使用标注时固定 annotation revision。
- [ ] 阶段以有界 typed records 交接，关闭 cursor 后交付帧；异常/取消释放 reader 和连接。
- [ ] 空阶段继续传播上游 semantic/limits；source 成功不能抹掉导航缺口。
- [ ] 页游标包含 query/stage/subject/page 与 expected revision；活动入口变化则按契约拒绝续页，不能偷偷换版本。
- [ ] 输出只计完整记录，returned 与实际字节一致；终态元数据都放不下时返回明确错误。
- [ ] deadline、工作量、记录、输出、源码页预算分别披露；下游重读只允许替换契约限定的证据。

验收：stage 中途发布、上游失败下游成功、空阶段、极小输出预算、慢读者和取消场景通过，且连接/引用可释放。

## P1-06：框架闭环

- [ ] Lombok mode=model 的声明 overlay 先于声明契约；modeled/partial/unmodeled 与 strict 门禁区分，不执行 annotation processor。
- [ ] Spring/SOFA 按已确认的依赖与分析顺序装配，XML inventory 共享但保留各自 producer/owner。
- [ ] 项目级分析看到完整逻辑事实视图；框架结果影响绑定时在 Java 内部迭代到稳定。
- [ ] Bean/配置关系与源码调用分型，generated provenance 可回溯到源码/资源/规则。
- [ ] producer 失败丢弃本轮部分产出并披露依赖能力；关闭 producer、删除 XML 或移除 Bean 清理旧事实和诊断。

验收：框架正向、关闭、XML 删除、解析失败、Lombok partial/strict 均有独立预期；不以“native 可启动”替代框架语义验收。

## P1-07：冷启动增量

- [ ] 按相同 IndexTarget 固定 baseline revision/profile，导出足够的事实/依赖/Bean/coverage/provenance，冷 worker 不依赖上次 AST。
- [ ] 编译计划分别声明 semantic inputs、publication sources、replacement owners；小 delta 允许完整编译上下文，缺输入不能偷偷读 live workspace。
- [ ] 对输入变更建立初始 owner 集；传播成功绑定、失败查找、继承/导入、Bean/XML 依赖至固定点。
- [ ] 最终 delta 完整声明替换范围；删除、失败、producer 停用可输出空 owner 替换，不靠外键级联掩盖证据。
- [ ] 基线不够返回 ReplanNeeded 并结束 attempt；有界扩大后退全量，失败保旧版；CAS 冲突不把旧 delta 贴到新 head。
- [ ] 停用语言/模块/world 清除对应当前 owners；没有任何语言启用时按配置契约拒绝新语义索引，已有历史仍可读。
- [ ] 热会话优化暂不开启或明确实验状态；未 PublishAck 的结果绝不成为基线。

验收：java-incremental 每个编辑步骤分别运行目标输入全量与旧版冷增量，比较规范化事实多重集、诊断、coverage 和 provenance；P1 框架也参与等价比较。
